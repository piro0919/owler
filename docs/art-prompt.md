# アイコンの依頼文

`assets/icon-source.png` は ChatGPT に次の文で作った。作り直すときはここから始める。
Hawky（昼の空の琥珀色から朱色、急降下する白い鷹）と対になるよう、夜の藍色と正面向きのフクロウにした。

## 1通目

```text
macOS のアプリアイコンの原画を1枚、画像で生成してください。

アプリ名は Owler。決まった時刻に動く仕事（定期実行）を、夜通し見張って結果を知らせる Mac アプリです。「夜の枝に止まって、大きな目で見張り続けるフクロウ」がモチーフです。

- 形式: 正方形 1024×1024。背景は四隅まで塗り切った正方形にしてください。角丸は付けないでください（こちらで付けます）
- 主役: 白いフクロウを1羽だけ。正面を向いて、ずんぐりした丸い体。顔の半分ほどを占める、大きくまん丸な目が2つ。目の中は琥珀色（#FFB23E 前後）で、黒い瞳がはっきり見えるように
- 画風: 白い影絵に、ごく淡い陰影だけを付けたフラットなベクター風。細い線や細かい羽の描き込みはしない。太い面で形を取る
- 背景: 左上の明るめの藍色（#3B4CCA 前後）から、右下の深い紺色（#141A4A 前後）への滑らかなグラデーション
- 余白: フクロウの全体が、外周20%の余白の内側に収まるように。どこも端で切らない
- 文字、ロゴ、枠、月、星、枝、床などは一切入れない
- 要素はフクロウと背景だけ

16px まで小さくしても、2つの大きな目でフクロウだと分かることが一番大事です。
```

# LP の見出しの横の絵

`lp/public/hero.png` は ChatGPT に次の文で作った。アイコンと同じ画風にして、Owler が見張り役であることを絵で見せる。

```text
Mac アプリのランディングページの、見出しの横に置くイラストを1枚、画像で生成してください。

アプリ名は Owler。決まった時刻に動く仕事（定期実行）を夜通し見張り、結果を記録する Mac アプリです。アイコンは「藍色の地に、正面を向いた白いフクロウ。目は琥珀色」です。このアイコンと同じフクロウが主役です。

- 形式: 横長 3:2（1536×1024）。四隅まで背景を塗り切ってください
- 場面: 夜。白いフクロウ1羽が、宙に浮かぶ暗い色の macOS 風の窓の上の縁に止まり、こちらを見て見張っている。窓の中には横長の行が5〜6本並び、各行の右端に小さな丸い印がある。印はほとんどが緑で、1つだけ赤
- フクロウ: アイコンと同じ、ずんぐりした白いフクロウ。大きなまん丸の琥珀色の目。柔らかい陰影の、つるっとした3D風
- 背景: 左上の藍色（#3B4CCA 前後）から右下の深い紺色（#141A4A 前後）への滑らかなグラデーション。窓の後ろに、目と同じ琥珀色の柔らかい光をうっすら
- 余白: フクロウと窓の全体が、外周15%の余白の内側に収まるように
- 窓の中を含め、文字・数字・ロゴは一切入れない。行は文字の代わりに、淡い灰色の横棒で表す
- 月、星、雲、木の枝は入れない。要素はフクロウと窓と背景だけ
```
